# 집의 다른 단위 — 한국 아파트 × 국내·미국 주식

Python으로 실행하는 로컬 웹사이트 v0.1입니다. Python 3.10 이상이면 추가 패키지 설치 없이 실행됩니다.

**포함된 모든 가격·환율·단지·종목은 가상 예시입니다. 실제 시세 자동 수집은 아직 연결하지 않았습니다.**

## 1. 실행하기

ZIP을 먼저 압축 해제하세요. `app.py`가 들어 있는 폴더에서 터미널을 열고 실행합니다.

Windows:

```powershell
py app.py
```

macOS / Ubuntu:

```bash
python3 app.py
```

브라우저에서 http://127.0.0.1:8000 에 접속합니다. 종료는 터미널에서 Ctrl+C입니다.
8000 포트를 다른 프로그램이 사용 중이면 `py app.py --port 8001` 또는 `python3 app.py --port 8001`로 실행하고 http://127.0.0.1:8001 에 접속합니다.

`py` 또는 `python3` 명령을 찾지 못하면 Python을 설치해야 합니다. 공식 배포: https://www.python.org/downloads/
Windows 설치 시 PATH 등록 옵션을 선택한 뒤 터미널을 다시 여세요.

이 서버는 내 컴퓨터에서만 접속하도록 설정되어 있습니다. 공개 운영용 서버가 아닙니다. HTML 파일을 직접 더블클릭하면 API가 없어 계산되지 않습니다.

## 2. 바로 해보기

- 초기 화면: 서울 성동구 예시 한강아파트, 2025-01-15, 국내 주식 A, 같은 날짜 → 12,000주.
- 미국 주식 B로 변경하고 가격 비교 → 1주 200달러 × 1,400원 = 280,000원. 12억 원은 약 4,285.71주, 정수로는 4,286주.
- 집 날짜만 2010-01-15로 변경 → 3억 원을 2025년 주가로 환산.
- 보유액 합산: 국내 주식 A 4,000주 + 미국 주식 B 100주 → 4억 2,800만 원. 예시 호수아파트 3억 5천만 원 사례가 나타납니다.
- 가격 직접 입력 탭 → 직접 아파트 가격·주가·환율·수량을 입력.

보유액 합산 목록은 왼쪽 비교 종목 수량과 별개입니다. 합산 목록에 입력한 수량은 선택한 주식 기준일 현재의 수량으로 해석합니다. 과거 수량을 현재로 자동 변환하지 않습니다.

## 3. 기능과 계산 기준

- 아파트 기준일과 주식 기준일을 독립적으로 선택합니다.
- 각 날짜 이전의 가장 최근 관측값을 사용하며 미래 관측값을 사용하지 않습니다.
- 미국 주식은 선택 날짜가 아닌 **실제로 사용한 주가 날짜** 이전의 최근 환율로 원화 환산합니다.
- 관측일과 출처, 요청 날짜 대비 경과일을 표시합니다. 오래된 데이터도 숨기지 않고 계산하므로 날짜를 꼭 확인하세요.
- 필요 주식 수 = 아파트 원화 가격 / 주식 원화 가격. 정수 주식 수는 올림합니다.
- 충당 비율 = 보유 주식 평가액 / 아파트 가격 × 100.
- 합산 평가액 이하인 아파트는 기준일 이전 가장 최근 관측 1건을 비교합니다. 실제 매물 조회가 아닙니다.
- 그래프는 선택한 **주가와 환율을 고정**하고 과거 집값만 바꿉니다. 주식분할을 무시한 수익률 비교 그래프가 아닙니다.
- 당시 실제 종가 기준의 가격 환산만 지원합니다. 수정주가, 주식분할/병합, 배당 재투자, 기업행위 조정은 미지원입니다.
- 세금·취득비용·거래 수수료·대출·물가 조정은 제외합니다.
- 직접 입력 모드의 날짜는 표시용 메타데이터이며, 입력 가격이 해당 시세인지 확인하지 않습니다.

## 4. 내 CSV 사용하기

`내 CSV 불러오기`에서 3개 파일을 함께 선택하세요. 오류가 있으면 기존 데이터는 유지합니다. 파일 합계 최대 6MB, 종류별 최대 50,000행입니다. UTF-8 또는 UTF-8 BOM으로 저장하세요. 저장하지 않으므로 새로고침하면 예시로 돌아갑니다. 원본 CSV는 별도로 보관하세요.

`data/`의 파일을 템플릿으로 복사해 사용할 수 있습니다. 헤더와 열 순서는 정확히 맞춰야 합니다.

### apartments.csv

```csv
id,name,region,area_m2,date,price_krw,source
MY_APT_84,내 아파트,서울 성동구,84,2025-01-15,1200000000,직접 확인한 자료
```

- 단지 + 전용면적 조합마다 고유 ID를 부여하세요. 같은 ID의 이름·지역·면적은 모든 날짜에 동일해야 합니다.
- `price_krw`는 **원**입니다. 원자료가 만원 단위라면 10,000을 곱해 변환하세요.
- `date`는 계약일입니다. 신고일이나 다운로드일을 섞지 마세요.
- 같은 ID·날짜는 1행만 허용합니다. 같은 날 거래가 여럿이면 대표 거래를 직접 고르고 출처에 선택 근거와 층 등을 기록하세요. 자동 중위값 집계는 하지 않습니다.
- 취소·해제된 거래를 제외하세요. 이 앱은 취소 여부를 판별할 원자료 필드가 없습니다.
- 국토교통부 원본 CSV를 그대로 읽는 기능은 없습니다. 이 스키마로 전처리해야 합니다.

### stocks.csv

```csv
id,name,currency,date,price,source
KR_005930,삼성전자,KRW,2025-01-15,100000,예시 형식 · 실제 가격 아님
US_AAPL,애플,USD,2025-01-15,200,예시 형식 · 실제 가격 아님
```

- 위 숫자도 실제 시세가 아닙니다. 직접 확인한 종가로 교체하세요.
- 국내와 미국 종목 ID가 겹치지 않게 접두사를 붙이세요.
- 통화는 KRW 또는 USD입니다. 단위는 원/주 또는 달러/주입니다.
- 가격은 당시 실제 거래 단위의 종가를 넣으세요. 수정주가를 넣으면 당시 실제 주식 수로 해석할 수 없습니다. 제공처에 따라 `Close`도 분할 조정될 수 있으니 해당 제공처의 정의를 확인하세요.
- 상장 전 데이터를 만들지 마세요. 기업행위 전후 가격을 연결해 투자수익률로 해석하지 마세요.

### fx.csv

```csv
date,krw_per_usd,source
2025-01-15,1400,예시 형식 · 실제 환율 아님
```

- 1달러에 해당하는 원화 금액입니다. 환율 종류(매매기준율 등)는 출처에 기록하고 일관되게 사용하세요.
- 국내 주식만 사용할 경우 헤더만 있는 fx.csv를 넣어도 됩니다.
- 미국 주식의 실제 주가 날짜 이전 환율이 없으면 오류를 표시합니다. 1원 등으로 대체하지 않습니다.

1980년 이후 날짜를 입력할 수 있지만 **데이터를 제공해야만** 계산됩니다. 예시 파일은 2010~2025년의 일부 관측값만 포함합니다. 주택가격지수를 원화 가격 칸에 넣으면 안 됩니다.

## 5. 코드 구조

| 파일 | 역할 |
|---|---|
| `app.py` | 로컬 HTTP 서버, 화면 제공, 계산 API |
| `core.py` | CSV 검증, 날짜 선택, 환율 변환, 주식 수·보유액 계산 |
| `static/index.html` | 브라우저 화면, 입력 처리, 결과 표와 SVG 그래프 |
| `data/*.csv` | 가상 예시 및 업로드 템플릿 |
| `test_core.py` | 날짜·환율·단위·오류·API 회귀 검사 |

브라우저가 입력을 JSON으로 보내면 `app.py`가 `core.py`의 함수를 호출하고 결과를 반환합니다. 계산의 핵심은 Python에 있으며, HTML/CSS/JavaScript는 화면과 사용자 입력을 담당합니다. Python 표준 라이브러리만 사용하므로 requirements.txt나 pip install이 필요 없습니다.

API:
- `GET /api/demo`: 예시 CSV 텍스트
- `POST /api/catalog`: CSV 검증과 선택 목록 생성
- `POST /api/calculate`: 직접 입력 / 데이터 기반 비교
- `GET /api/health`: 실행 상태

## 6. 검사

```bash
python3 -m unittest -v
```

Windows에서는 `py -m unittest -v`를 사용하세요. 핵심 숫자는 Decimal로 계산하고, 브라우저 표시용 JSON에서 숫자로 변환합니다.

## 7. 다음 개발 단계

1. 국토교통부 실거래 API 연결: 지역 코드·계약월 수집, 취소 거래 제거, 면적/단지 식별, 중복 처리, 로컬 DB 저장.
2. 국내·미국 주가 제공처 선정: 과거 데이터 범위, 원주가/수정주가 정의, 호출·재배포 권한 확인.
3. 일별 환율 수집과 출처 기록.
4. 주식분할을 반영한 별도 비교 모드. 배당 포함 투자 시뮬레이션과 단순 가격 환산 구분.
5. 장기 주택가격지수 비교: 개별 실거래와 구분한 별도 화면. 1980년대 데이터 공백 명시.
6. 공개 배포 시 운영용 웹서버·인증·캐시·DB·요청 제한 추가.
