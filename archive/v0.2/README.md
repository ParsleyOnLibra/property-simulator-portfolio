# 집의 다른 단위 v0.2 — 자동 수집 · 영구 저장

한국 아파트와 국내·미국 주식의 서로 다른 시점 가격을 비교하는 Python 로컬 웹앱입니다.
**Python 3.10 이상, 외부 패키지 설치 없음.** 인터넷은 자료 수집에 필요하고, 저장된 자료 비교는 오프라인에서도 가능합니다.

## 1. 실행 / 이전 버전에서 변경

1. 기존 v0.1 서버 터미널에서 Ctrl+C로 종료합니다.
2. 새 ZIP을 다른 폴더에 압축 해제합니다.
3. Windows는 `start_windows.bat`를 더블클릭하거나, VS Code에서 `app.py`가 있는 폴더의 터미널을 열고 실행합니다.

```powershell
py app.py
```

Mac / Ubuntu:

```bash
python3 app.py
```

브라우저에서 http://127.0.0.1:8000 접속. 종료는 Ctrl+C.
포트 사용 중이면 `py app.py --port 8001`로 실행하고 http://127.0.0.1:8001 에 접속합니다.
Python 설치가 필요하면 https://www.python.org/downloads/ 에서 설치하세요.

서버는 내 컴퓨터(127.0.0.1)에서만 접속할 수 있습니다. 공개 인터넷 배포용 서버가 아닙니다.
HTML 파일을 직접 더블클릭하거나 VS Code Live Server로 열지 말고 Python 서버의 주소로 접속하세요.

## 2. 처음 실제 자료 수집하기

1. 화면의 **자동 수집 · 저장**을 엽니다.
2. [국토교통부 아파트 매매 실거래가 자료](https://www.data.go.kr/data/15126469/openapi.do)에서 활용신청하고 승인된 일반 인증키(Decoding)를 발급받습니다.
3. 앱의 비밀번호 모양 입력칸에 키를 붙여넣습니다. 채팅으로 키를 보내지 마세요.
4. 지역 코드를 입력합니다. 초기값은 서울 성동구 `11200`입니다.
5. 종목 코드를 입력합니다. 초기값은 삼성전자 `005930.KS`, 애플 `AAPL`입니다.
6. 시작일과 종료일을 지정하고 **수집 시작 / 갱신**을 누릅니다.
7. 완료 또는 일부 실패 메시지와 오류 목록을 확인합니다. **저장된 자료로 비교**를 누릅니다.

2000년부터 현재까지 첫 수집은 아파트만 약 250개월의 API 요청이 필요할 수 있어 수분 이상 걸립니다. 처음 연결 확인은 최근 1개월로 해도 됩니다. 이후 시작일을 2000-01-01로 변경해 전체 요청 기간을 수집하세요.

공공데이터포털 키가 없으면 주식·환율은 수집하고 아파트는 실패 이유를 표시합니다. 실제 아파트 자료가 확보되기 전에는 실제 자료 비교 모드로 전환하지 않습니다. 예시 아파트와 실제 주식을 조용히 섞지 않습니다.

## 3. 수집 범위와 데이터 정의

| 자료 | 제공처 | 범위 / 의미 |
|---|---|---|
| 아파트 | 국토교통부 매매 실거래 Open API | 2006년 이후 신고된 거래. 시군구·계약월 단위 |
| 국내·미국 주식 / ETF | Yahoo Finance chart 응답 | 2000년 이후 제공 가능한 일별 가격. 상장 전/미제공 날짜는 생성하지 않음 |
| 원·달러 환율 | Frankfurter v1 / ECB | 2000년 이후 제공 가능한 일별 USD/KRW 교차 기준환율 |

- Yahoo 연동은 비공식 인터페이스입니다. 제공처 변경·차단·호출 제한에 따라 실패할 수 있습니다. 실패 이유를 표시하고 기존 자료를 보존합니다. 공개/상업 서비스 전에는 주가 사용·재배포 조건에 맞는 제공처를 별도로 확정해야 합니다.
- Frankfurter v1은 공식 문서에서 계속 지원되는 API이며 ECB 자료를 제공합니다. 환전 수수료를 포함한 은행 매수·매도 환율이 아닙니다.
- 요청 날짜 이전의 최근 관측값을 사용하고 실제 사용한 날짜를 표시합니다. 과거 시점에 당시 공개되어 있었던 자료만 재현하는 백테스트는 아닙니다. 현재까지 정정된 기록을 과거 계약일에 연결합니다.
- 2000~2005년 아파트 실거래는 이 API로 수집하지 않습니다. 자료 없음으로 처리합니다.
- 전 지역/전 종목 자동 전수 수집이 아니라 관심 시군구(한 번에 최대 5개)·종목(최대 10개)을 수집합니다. 반복 실행하면 DB에 범위를 추가할 수 있습니다.
- 과거 행정구역 변경으로 코드가 달라진 지역은 이전 코드를 별도로 수집해야 할 수 있습니다. 코드 변경 이력 자동 연결은 미지원입니다.

### 아파트 처리

- API 페이지를 모두 받은 뒤, 해당 지역·월을 한 번의 DB 트랜잭션으로 교체합니다. 중간 실패 시 기존 월 데이터를 보존합니다.
- 취소/해제 표시가 있는 거래를 계산에서 제외합니다. 재수집 시 나중에 취소된 거래도 제거됩니다. 원본 응답은 DB에 최근 수집 단위별로 남깁니다.
- 단지명 + 지역코드 + 법정동 + 지번 + 전용면적으로 식별합니다. 단지명/주소 변경 시 별도 단지로 잡힐 수 있습니다.
- 같은 단지·면적·계약일의 여러 거래는 **중위값**으로 집계합니다. 짝수 건의 중위값은 실제 거래가와 다를 수 있습니다. 건수·최저·최고 금액을 출처에 함께 표시합니다.
- API의 만원 단위를 원으로 변환합니다. 층·동·조망·리모델링 차이를 보정한 시세가 아닙니다.
- 시작/종료 날짜가 월 중간이어도 아파트는 해당 월 전체를 가져옵니다. 비교 계산은 선택 기준일 이후 관측값을 사용하지 않습니다.

### 주식분할 처리

Yahoo의 `Close`는 분할 조정된 값일 수 있습니다. 배당까지 조정된 `Adj Close`를 사용하지 않고, 제공되는 분할 이벤트를 이용해 `Close × 해당 날짜 이후 누적 분할배수`로 당시 단위의 가격을 역산합니다.

예: 4:1 분할 전 조정 종가가 125달러이면 당시 가격은 약 500달러로 계산합니다. 분할 효력일의 종가에는 그날 분할을 다시 적용하지 않습니다. 요청 종료일 이후의 분할 정보도 받아야 하므로 주가 원본은 요청 시작일부터 수집 시점까지 요청하며, 저장은 선택 기간만 합니다.

**이 값은 '분할역산 추정 종가'입니다.** 제공처 분할 누락·조정 오류·기타 기업행위는 자동 교정할 수 없고, 공식 원주가를 그대로 받은 것이 아닙니다. 수익률/배당 재투자/분할 후 보유수량 자동 변환 기능은 아닙니다. 입력 수량은 선택한 주식 날짜 당시의 수량으로 해석합니다.

오늘 현지 날짜의 일봉은 장중 값일 수 있어 제외하고, 거래량 0으로 표시된 행도 제외합니다. 실시간 주가 서비스가 아닙니다.

## 4. 저장 / 자동 갱신

- `local_data/market.sqlite3`에 관측값, 최근 수집 단위의 원본 응답, 수집 조건을 저장합니다.
- 새로고침·서버 재시작 후에도 DB를 다시 읽습니다. 파일을 삭제하면 수집 자료가 없어집니다.
- 앱을 옮길 때 `local_data` 폴더도 함께 옮기면 자료를 유지할 수 있습니다.
- 주식·환율은 다시 요청한 날짜 범위만 교체하고 그 밖의 저장 날짜는 유지합니다. 아파트는 요청한 지역·월 전체를 교체합니다.
- 수집 중지 시 이미 완료된 단위는 유지합니다. 현재 진행 중인 네트워크 호출은 타임아웃/재시도 종료까지 기다릴 수 있습니다.
- 같은 제공처에서 연속 3회 실패하면 해당 제공처의 나머지 요청을 건너뛰고 오류를 표시합니다.
- **서버 실행 중 24시간마다 자동 갱신**을 체크하면 마지막 수집 시도 이후 24시간이 지났을 때 같은 지역·종목을 시작일부터 오늘까지 다시 수집합니다. 최근 월뿐 아니라 선택한 과거 전체 범위를 갱신하므로 정정·취소도 반영됩니다.
- 자동 갱신은 브라우저가 아니라 Python 서버에서 실행합니다. 서버가 꺼져 있으면 동작하지 않습니다. 다음 시작 시 24시간이 지났으면 다시 실행합니다. 끄려면 앱에서 **자동 갱신 끄기**를 누르세요.
- 진행률의 '단위'는 아파트 지역/월, 주식 종목, 환율 연도입니다. 성공 단위에 0건 응답도 포함될 수 있습니다. 일부 실패를 전체 성공으로 표시하지 않습니다.

### 인증키 보관

화면에 입력한 키는 서버 메모리에만 보관하고, SQLite·로그·ZIP에 저장하지 않습니다. 서버를 재시작하면 다시 입력하세요. 화면을 새로고침하는 것만으로는 서버 메모리가 지워지지 않습니다.

재시작 후에도 자동 갱신을 원하면 다음 중 하나를 직접 설정할 수 있습니다.

- 환경변수 `DATA_GO_KR_KEY`에 키 설정
- `local_data/api_key.txt` 파일을 직접 만들고 인증키만 한 줄로 저장

`api_key.txt`는 평문 파일이므로 개인 컴퓨터에서만 관리하고 다른 사람에게 프로젝트를 전달할 때 제외하세요. `.gitignore`에는 local_data 전체가 제외되어 있습니다.

## 5. 계산 / 화면

- 필요 주식 수 = 아파트 원화 가격 / 주식 원화 가격. 정수 수량은 올림합니다.
- 미국 주식 원화 가격 = 달러 주가 × 실제 주가 날짜 이전 최근 환율.
- 아파트 기준일과 주식 기준일은 독립적으로 선택합니다.
- 보유 종목 목록은 왼쪽 비교 종목 수량과 별개로 합산합니다. 실제 자료로 전환할 때 보유 수량은 0으로 초기화합니다.
- 합산 평가액 이하의 아파트 관측 사례는 현재 판매 매물이나 실제 구매 가능 보장이 아닙니다. 세금·거래비용·대출은 제외합니다.
- 그래프는 선택한 주가·환율을 고정하고 과거 집값만 바꾸는 기록입니다.
- 직접 입력 모드와 가상 예시 모드를 그대로 유지합니다. 예시 CSV는 실제 자료가 아닙니다.

## 6. CSV 임시 불러오기


`내 CSV 불러오기`에서 3개 파일을 함께 선택하세요. 오류가 있으면 기존 데이터는 유지합니다. 파일 합계 최대 6MB, 종류별 최대 50,000행입니다. UTF-8 또는 UTF-8 BOM으로 저장하세요. CSV는 임시 비교용입니다. 새로고침하면 자동 수집 DB(없으면 예시)로 돌아갑니다. 원본 CSV는 별도로 보관하세요.

`data/`의 파일을 템플릿으로 복사해 사용할 수 있습니다. 헤더와 열 순서는 정확히 맞춰야 합니다.

### apartments.csv

```csv
id,name,region,area_m2,date,price_krw,source
MY_APT_84,내 아파트,서울 성동구,84,2025-01-15,1200000000,직접 확인한 자료
```

- 단지 + 전용면적 조합마다 고유 ID를 부여하세요. 같은 ID의 이름·지역·면적은 모든 날짜에 동일해야 합니다.
- `price_krw`는 **원**입니다. 원자료가 만원 단위라면 10,000을 곱해 변환하세요.
- `date`는 계약일입니다. 신고일이나 다운로드일을 섞지 마세요.
- 같은 ID·날짜는 1행만 허용합니다. 같은 날 거래가 여럿이면 대표 거래를 직접 고르고 출처에 선택 근거와 층 등을 기록하세요. 자동 중위값 집계는 하지 않습니다.
- 취소·해제된 거래를 제외하세요. 이 앱은 취소 여부를 판별할 원자료 필드가 없습니다.
- 국토교통부 원본 CSV를 그대로 읽는 기능은 없습니다. 이 스키마로 전처리해야 합니다.

### stocks.csv

```csv
id,name,currency,date,price,source
KR_005930,삼성전자,KRW,2025-01-15,100000,예시 형식 · 실제 가격 아님
US_AAPL,애플,USD,2025-01-15,200,예시 형식 · 실제 가격 아님
```

- 위 숫자도 실제 시세가 아닙니다. 직접 확인한 종가로 교체하세요.
- 국내와 미국 종목 ID가 겹치지 않게 접두사를 붙이세요.
- 통화는 KRW 또는 USD입니다. 단위는 원/주 또는 달러/주입니다.
- 가격은 당시 실제 거래 단위의 종가를 넣으세요. 수정주가를 넣으면 당시 실제 주식 수로 해석할 수 없습니다. 제공처에 따라 `Close`도 분할 조정될 수 있으니 해당 제공처의 정의를 확인하세요.
- 상장 전 데이터를 만들지 마세요. 기업행위 전후 가격을 연결해 투자수익률로 해석하지 마세요.

### fx.csv

```csv
date,krw_per_usd,source
2025-01-15,1400,예시 형식 · 실제 환율 아님
```

- 1달러에 해당하는 원화 금액입니다. 환율 종류(매매기준율 등)는 출처에 기록하고 일관되게 사용하세요.
- 국내 주식만 사용할 경우 헤더만 있는 fx.csv를 넣어도 됩니다.
- 미국 주식의 실제 주가 날짜 이전 환율이 없으면 오류를 표시합니다. 1원 등으로 대체하지 않습니다.

조회 범위는 2000년 이후입니다. 자동 수집이나 CSV로 확보한 날짜만 계산합니다. 예시 파일은 2010~2025년의 일부 관측값만 포함합니다. 주택가격지수를 원화 가격 칸에 넣으면 안 됩니다.


## 7. 코드 구조

| 파일 | 역할 |
|---|---|
| `app.py` | 로컬 웹서버와 API |
| `core.py` | 환산 계산, 날짜 선택, CSV 검증 |
| `providers.py` | 국토부·Yahoo·Frankfurter 요청 및 응답 처리 |
| `storage.py` | SQLite 저장, 범위별 원자적 교체 |

검사 명령: `py -m unittest -v` (Mac은 `python3 -m unittest -v`).

## 8. 검증 상태와 제한

- 핵심 계산, 날짜 선택, 환율 방향, 분할 역산, 취소 거래 제외, 페이지 누락, DB 교체/롤백 및 API를 테스트했습니다.
- 실제 외부 호출로 삼성전자·애플의 분할 전후 구간과 원·달러 환율 응답 수집을 확인했습니다.
- **아파트 API는 사용자 인증키가 없어 실제 인증 수집을 검증하지 못했습니다.** XML 응답 및 갱신 경로는 테스트 데이터를 사용했습니다. 실제 키로 호출했을 때 제공처 오류가 나면 앱에 표시되는 메시지를 확인하세요.
- 브라우저 시각 검증은 하지 못했습니다. JavaScript 문법과 HTTP/API는 검사했습니다.
- 날짜 기반의 지역/종목 조회 서비스이며 가격 예측이나 투자 성과 백테스트는 아닙니다.
