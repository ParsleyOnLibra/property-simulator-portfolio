# 집의 다른 단위 v0.4 — 고정 40종목 + 직접 추가

## 변경 내용

- 전체 시장 순위 API 호출을 중단했습니다. 금융위원회 주식시세정보 승인은 이 버전에 필요하지 않습니다.
- `data/watchlist.json`에 국내 20개·미국 20개 기본 목록을 포함합니다.
- 화면의 **종목 추가 · 제거**에서 한 줄에 `종목코드,표시이름`을 입력하고 **종목 목록 저장**을 누릅니다. 최대 200개입니다.
- 저장 후 주식 수집을 실행하면 등록 목록만 수집합니다. 이전 순위·수집 설정이 DB에 있어도 전체 시장 조회는 실행하지 않습니다.
- 비교 선택에는 등록한 종목만 표시합니다. 미수집 종목은 표시하며 실제 계산은 가격을 수집해야 가능합니다.
- 목록을 제거해도 과거 주가 DB는 삭제하지 않습니다. 목록 변경은 SQLite에 저장되어 재시작 후 유지됩니다.
- 사용자가 등록 목록을 바꾸면 기본 출처 설명은 최초 목록의 설명으로만 해석합니다.

## 초기 목록 근거와 한계

조회일: 2026-10-16. 이 목록은 고정된 기본 비교 대상이며 자동 순위 서비스가 아닙니다.

- 국내: https://maedong.kr/screen/value-top 의 2026-10-15 거래대금 상위 20 목록. 타 출처와 금액·구성 차이가 있어 전 시장 공식 확정 순위라고 인증하지 않습니다. 국내는 해당 출처의 거래대금 기준이며 미국의 가격×거래량 기준과 구분합니다.
- 미국: https://www.tradingview.com/markets/stocks-usa/market-movers-active/ 조회 표의 Price × vol 상위 20. 페이지에 거래일이 명시되지 않아 목록에는 조회일만 기록했습니다. 완료 거래일 확정 순위로 검증한 것은 아닙니다.
- 두 출처에서 종목 식별 목록만 구성했습니다. 조회 화면의 시세는 계산 데이터로 넣지 않았습니다. 비교 가격은 선택 기간의 완료 일봉을 별도로 수집합니다.
- 새 상장 종목은 2000년까지 자료가 존재하지 않습니다. 제공처가 지원하지 않는 종목은 오류로 표시하며 가격을 만들어 넣지 않습니다.
- 주가 공개 이용권 문제는 고정 목록으로 해결되지 않습니다. 공개용 공급처는 별도 선정이 필요합니다.

## 실행 및 기존 데이터 유지

1. 이전 서버를 종료합니다.
2. 새 ZIP을 새 폴더에 풉니다.
3. 기존 `local_data` 폴더를 백업하고, 새 `app.py` 옆으로 복사합니다. 인증키 파일도 그대로 유지됩니다.
4. Windows: `start_windows.bat` 실행. VS Code: `py app.py --port 8003` 실행 후 http://127.0.0.1:8003 접속.
5. 아파트·주식·환율 중 원하는 대상만 선택해 수집합니다. 주식은 등록 목록만 조회합니다.

아파트 서울 전체 최초 수집은 여전히 구별·월별 수천 작업이 필요합니다. 이번 변경은 주식 전 종목 조회를 제거하는 변경입니다.
아파트 키는 `local_data/api_key.txt`에 Decoding 키만 한 줄로 저장하고 서버를 재시작하면 자동으로 읽습니다.
Python 3.10 이상. 추가 패키지 설치 없음. 로컬 개발 전용이며 관리자·방문자 인증 분리는 아직 없습니다.

## 검증

계산·API·저장·기존 DB 이전 및 고정 목록 동작을 자동 테스트합니다. `python3 -m unittest -q` 또는 Windows `py -m unittest -q`.
고정 목록 테스트: 전체 순위 함수가 호출되지 않음, 지정 종목만 수집, 40종목 기본 목록, 종목 추가/제거/중복 거부, 재시작 후 유지.
브라우저 시각 검증은 미실시. JavaScript 문법 검사 및 HTTP API 테스트 수행.

## 계산 기준

필요 주식 수 = 아파트 원화 가격 / 주식 원화 가격. 미국 주가에는 실제 주가 관측일 이전 최근 환율을 적용합니다.
아파트는 선택일 이전 최근 거래일의 단지·면적별 중위값이며 매물 가격이 아닙니다.
주가는 Yahoo 분할 이벤트로 역산한 당시 단위의 추정 종가로 공식 원주가를 보장하지 않습니다. 수익률 백테스트가 아닙니다.
주식·환율 제공처의 공개 이용 조건은 별도 검토 대상입니다.
CSV 형식은 data/*.csv를 참고하세요. 해당 CSV는 가상 예시입니다.
