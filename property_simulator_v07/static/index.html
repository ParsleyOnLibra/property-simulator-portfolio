A DIFFERENT WAY TO MEASURE A HOME

이 집은, 주식 몇 주일까?

집 한 채의 가격을 현재 또는 과거 특정 날짜의 주식 수로 환산합니다.

예시 데이터 · 모든 가격·환율·아파트는 기능 시연을 위한 가상 값입니다. 실제 시세가 아닙니다.

실제 데이터 자동 수집

지정한 단지·종목의 기간을 선택하면 자료를 내려받아 이 컴퓨터에 저장합니다. 아파트는 2006년부터, 주식·환율은 2000년 이후 제공 가능한 날짜만 수집합니다.

국토교통부 아파트 매매 실거래 API 활용신청 ↗
아파트 API와 오피스텔 매매 API 모두 활용신청한 키를 사용하세요. 기존 키 파일은 그대로 읽습니다. 주식 목록은 고정 등록 방식으로, 국내 순위 API를 호출하지 않습니다. 키를 채팅으로 보낼 필요는 없습니다.

지정 부동산 8개: 한남더힐 · 트리마제 · 압구정 현대 · 은마 · 나인원 한남 · 래미안 원베일리 · 타워팰리스 · 시그니엘(롯데월드타워).

아파트는 용산·성동·강남·서초 4개 구, 시그니엘은 송파구 오피스텔 API를 조회하고 지정 단지만 저장합니다. 구·월 단위 API이므로 단지 8개가 요청 8회를 뜻하지는 않습니다.


아파트는 선택일이 포함된 월 전체를 수집합니다. 같은 단지·면적·계약일의 거래가 여러 건이면 중위값으로 표시합니다. 주식은 Yahoo의 분할 정보를 역산한 추정 종가이며 기업행위 누락 시 오차가 생길 수 있습니다.

저장 상태 확인 중

처음에는 최근 1년부터 수집합니다. 더 오래된 비교가 필요하면 시작일을 앞당기세요. 기존 과거 월은 재사용하고 최근 6개월 안팎을 다시 조회합니다. 중지해도 완료된 자료는 보존됩니다.

내 가격 데이터 연결

아래 3개 CSV를 한 번에 교체합니다. 업로드한 값은 출처 검증 없이 계산에 사용하며, 새로고침하면 저장된 자동 수집 자료(없으면 예시 자료)로 돌아갑니다. 각 파일은 UTF-8 형식으로 저장하세요.

열 형식은 프로젝트의 data/ 예시와 README.md를 참고하세요. 아파트 금액은 원 단위, 환율은 1달러당 원입니다. 주가는 당시 실제 종가만 넣으세요. 수정주가·가격지수·취소 거래는 지원하지 않습니다.

종목 추가 · 제거

한 줄에 종목코드,표시이름을 입력하세요. 저장하면 비교 목록과 다음 수집 대상에 반영됩니다. 제거해도 기존 주가 기록은 삭제하지 않습니다.

예: 035720.KS,카카오 또는 NFLX,넷플릭스. 추가한 종목은 주식 수집 후 가격 비교가 가능합니다.

집값 ÷ 입력한 주가로 환산합니다. 그래프에서 날짜를 누르면 그날의 종가를 가져옵니다.

선택일 이전의 가장 최근 관측값을 사용합니다. 미국 주식 환율은 실제 주가 날짜 이전의 최근 값입니다.

계산 기준 알아보기

필요 주식 수 = 집값 ÷ 원화 주가
미국 주식 원화 주가 = 달러 주가 × 환율
정수 단위로 환산할 때는 올림합니다.

당시 1주 단위의 가격 환산입니다. 자동 수집 주가는 분할 조정을 역산한 추정값이며, 제공처 기업행위 오류를 보정하지 못할 수 있습니다. 배당·세금·수수료·대출·취득비용은 제외합니다. 과거 매수 후 현재 보유 수익률을 계산하는 기능이 아닙니다.

거래가 없는 날짜의 집값은 최근 관측값일 뿐 현재 매물 가격이 아닙니다. 표본 수나 층별 차이도 자동 보정하지 않습니다.

선택 종목의 주가 기록

저장된 일별 종가 기준입니다. 주식분할 전후 단위가 달라질 수 있으며 장중 고가·저가는 표시하지 않습니다. 가로선은 입력 가격 수준이며, 특정 날짜에 정확히 그 가격으로 거래되었다는 뜻은 아닙니다.
