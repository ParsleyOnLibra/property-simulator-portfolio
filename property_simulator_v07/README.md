## v0.5에서 가장 간단하게 업데이트하기

1. 실행 중인 서버를 Ctrl+C로 종료합니다.
2. 이 ZIP의 `static/index.html`과 `core.py`를 기존 v0.5 폴더의 같은 위치에 덮어씁니다.
3. 기존 폴더에서 `python3 app.py --port 8003`으로 실행합니다.
4. 브라우저를 새로고침하여 v0.6 표시를 확인합니다.

`local_data`는 건드리지 않습니다. 저장된 가격과 인증키를 다시 수집/입력할 필요 없습니다. 새 폴더에서 실행하려면 기존 `local_data` 폴더를 새 `app.py` 옆으로 복사하세요.

현재 날짜를 선택해도 실시간 가격을 가져오는 것은 아닙니다. 저장된 자료 중 선택일 이전 최근 완료 종가와 실거래를 사용하며, 실제 관측일을 표시합니다.

# 집의 다른 단위 v0.5 — 지정 주식·ETF 17개와 부동산 8개

## 시작하기 / 기존 버전에서 옮기기

1. 기존 서버 창에서 Ctrl+C로 종료합니다.
2. 새 ZIP을 새 폴더에 풉니다.
3. 기존 `local_data` 폴더를 백업한 뒤 새 `app.py` 옆으로 복사합니다. `market.sqlite3`와 `api_key.txt`를 그대로 유지합니다.
4. 새 폴더에서 Windows `py app.py --port 8003`, Mac/Linux `python3 app.py --port 8003` 실행 후 http://127.0.0.1:8003 에 접속합니다. 화면 버전 v0.5를 확인하세요. `start_windows.bat`은 기본 8000 포트를 사용합니다.
5. 데이터 수집 탭에서 기간을 확인하고 **수집 시작 / 갱신**을 누릅니다. 첫 화면 기본 기간은 최근 1년입니다. 과거 비교가 필요하면 시작일을 앞당기세요.

Python 3.10 이상, 추가 패키지 없음. 서버 종료는 Ctrl+C이며 브라우저를 닫아도 서버는 계속 실행됩니다. 24시간 자동 갱신은 서버가 실행 중일 때만 작동합니다.

하나의 임의 대표 가격으로 면적을 섞지 않습니다. 실제 거래가 수집된 단지·차수·전용면적을 선택합니다. 같은 계약일·단지·면적의 복수 거래는 중위값이며 취소된 거래는 제외합니다. 매물 호가나 단지 전체 감정가가 아닙니다.

국토부 API는 구·월 단위로 조회하므로 아파트 4개 구와 오피스텔 1개 구를 월별 조회한 후 지정 단지만 저장합니다. 서울 25개 구나 주식 전체 시장 순위는 조회하지 않습니다. 1개월은 기본 부동산 요청 5개이며 응답 페이지가 많으면 추가 요청이 필요합니다. 기존 과거 월은 재사용하고 최근 6개월 안팎은 갱신합니다. 오래된 거래 취소까지 반영하려면 과거 재확인 옵션을 켜세요.

기존 DB를 가져오면 다른 아파트 기록은 보존하지만 비교 목록과 보유액 이하 가격 사례에서 제외됩니다. 수집 상태의 DB 통계에는 보존된 과거 전체 기록도 포함됩니다. 단지 이름·법정동 매칭 규칙은 `housing.py`에 있습니다. 제공처가 이름을 바꾸면 규칙 추가가 필요할 수 있습니다.

## 인증키 — 시그니엘은 별도 API 활용승인 필요

기존 `local_data/api_key.txt`가 있으면 다시 입력할 필요가 없습니다. 파일에 Decoding 키만 한 줄로 저장합니다. 환경변수 `DATA_GO_KR_KEY`가 설정되어 있으면 파일보다 우선합니다. 화면에서만 입력한 키는 서버 종료 시 사라집니다.

아래 두 API의 활용신청을 확인하세요. 같은 키라도 각각 이용 권한이 있어야 합니다.

- 아파트 매매: https://www.data.go.kr/data/15126469/openapi.do
- 오피스텔 매매(시그니엘): https://www.data.go.kr/data/15126464/openapi.do

시그니엘 수집이 실패해도 아파트·주식의 성공 자료는 보존됩니다. 공급처 오류나 거래 없음은 0원/가상 가격으로 대체하지 않습니다. 신규 종목은 상장 이전 가격이 없으며 공급처에 아직 등록되지 않았다면 별도 오류가 표시됩니다.

## 계산과 이용 범위

필요 주식 수 = 부동산 원화 가격 / 주식 원화 가격. 각각 선택 기준일 이전의 최근 관측값을 사용하며, 미국 주가 환율은 실제 주가 관측일 이전 최근 환율입니다. 오래된 실거래를 현재 호가처럼 취급하지 말고 실제 관측일을 확인하세요.

주가는 Yahoo 일봉과 분할 이벤트를 이용해 당시 단위로 역산한 추정 종가입니다. 배당 미조정이며 공식 원주가를 보장하지 않습니다. 그래프는 선택 주가를 고정하고 과거 집값을 환산하며 투자수익률 백테스트가 아닙니다.

초기 실행에서 가상 예시를 자동으로 보여주지 않습니다. 수집 전에는 빈 상태와 17개 등록 종목이 나타납니다. CSV 화면의 명시적인 예시 버튼은 기능 시연용 가상 데이터입니다.

이 버전은 내 컴퓨터에서만 실행하는 로컬 앱입니다. 공개 서비스용 관리자 인증과 데이터 재배포 계약은 포함되지 않습니다.
