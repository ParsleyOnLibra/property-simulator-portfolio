주가 직접 입력 + 주가 그래프 업데이트 (v0.7)

1. 기존 서버를 Ctrl+C로 종료합니다.
2. 이 압축파일의 아래 5개 파일을 기존 프로젝트 폴더의 같은 위치로 복사합니다.
   app.py
   core.py
   storage.py
   pricing.py (새 파일)
   static/index.html
3. 기존 폴더에서 python3 app.py --port 8003 실행.
4. 브라우저 새로고침. v0.7 표시를 확인합니다.

local_data 폴더를 삭제하거나 덮어쓰지 마세요.
이미 수집한 자료, 인증키, 편집한 종목 목록은 그대로 사용합니다.

사용법
- 부동산 단지·면적과 부동산 기준일을 정합니다.
- 종목을 고르면 저장된 종가 그래프가 나타납니다.
- '주가를 직접 입력'에서 1주 가격을 입력하면 자동 환산됩니다.
- 주황색 가로선은 입력 가격, 점은 가장 가까운 저장 종가입니다.
- 아래 날짜 버튼 또는 그래프를 클릭하면 그날의 종가로 바로 환산합니다.
- 같은 가격대의 날짜가 여러 개일 수 있습니다. 입력 가격을 특정 날짜의 실제 가격으로 단정하지 않습니다.
- 미국 종목은 달러 가격과 원/달러 환율을 사용합니다.
  환율은 처음에 최신 저장값으로 채워지고 날짜가 표시됩니다.
  그래프에서 과거 주가를 눌러도 환율은 유지됩니다. 필요하면 직접 바꾸세요.
- 과거 날짜에 맞는 자동 환율까지 사용하려면 '날짜의 저장된 종가 사용'으로 전환하세요.
- 주가 기록이 없으면 수집 후 그래프가 나타납니다. 주가·환율 직접 입력 계산은 가능합니다.
